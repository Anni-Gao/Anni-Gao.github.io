A Beginner's Guide to ACM Algorithms

2026-01-02 Updated by 2026-10-31 2.1k Words About 8 mintues reading

Introduction

Algorithms are the foundation of computer science.

This blog is a beginner-friendly introduction to ACM competitive programming algorithms.

Instead of simply presenting algorithms and code, this guide focuses on the thinking process behind solving problems:

Understand the problem → Build a simple solution → Analyze limitations → Optimize the algorithm.

The purpose of this blog is not to help you memorize algorithms, but to teach you how to think like an algorithm designer.

Part 1: The Beauty of Brute Force — Enumeration and Simulation

When beginners start learning competitive programming, they often misunderstand one thing:

“Is brute force too simple? Shouldn’t advanced programmers always use sophisticated algorithms?”

The answer is no.

In ACM programming contests, the only thing that matters is:

If an algorithm can pass all test cases within the given constraints, it is a correct solution.

Brute force is not a “low-level” technique. In many cases, it is the most reliable and easiest-to-verify approach.

In fact, many advanced algorithms are developed from brute-force ideas:

  1. Enumerate all possible solutions.
  2. Identify the performance bottleneck.
  3. Remove unnecessary computation.
  4. Apply optimization techniques such as pruning, dynamic programming, greedy strategies, or data structures.

Therefore, mastering brute force is the first step toward becoming a strong algorithm competitor.

1. Enumeration (Brute Force)

1.1 What is Enumeration?

Enumeration, also known as brute force, is a method that:

Searches through all possible states and checks whether each state satisfies the requirements.

Example. Given an array [1, 2, 3, 4], find two numbers whose sum equals 5.

A brute-force approach tries every possible pair:

Pair Sum Match
(1, 2) 3 ❌
(1, 3) 4 ❌
(1, 4) 5 ✅
(2, 3) 5 ✅
(2, 4) 6 ❌
(3, 4) 7 ❌

Among them, (1, 4) and (2, 3) sum to 5.

Although this method is not always efficient, it has several advantages:

  • Simple implementation
  • Easy debugging
  • Easy correctness verification

For small input sizes, brute force is often the best solution.
